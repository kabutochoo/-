# App Store掲載文案（所有者の確認用）

名前：皇居RUNLOO

サブタイトル案：また走る、また関わる。ランナー手帳

プロモーション文案：
皇居で出会ったランナーのことも、自分のRUNの記録も。前回と違う、新しい自分につながる個人用のランニング手帳。

説明文案：
皇居RUNLOOは、皇居で出会った人を覚えておくためのランナー手帳です。

ニックネーム、出会った日、特徴、会話や交換した情報をメモ。ニックネームや会話の言葉で検索し、また会ったときに思い出せます。手帳は後から編集・削除できます。

RUNの計測では分・秒・百分の一秒を表示。一時停止・再開に対応し、日付・距離・タイム・今日のメモを保存できます。同じ距離の前回の記録や5kmのベストも振り返れます。手入力で過去の記録も追加できます。

主な機能
・出会ったランナーの個人用メモ、編集、検索、削除
・RUNのタイム計測、保存、距離別の前回比較
・オフラインでの利用
・JSONバックアップの書き出しと復元

記録は端末内に保存されます。アカウント登録や、他の利用者との公開投稿・メッセージ、自動同期の機能はありません。Web版との引き継ぎにはバックアップファイルを使います。アプリを削除すると記録が失われることがあるため、大切な記録はバックアップしてください。

連絡先などは相手の了承を得た情報だけ記録してください。GPSでの距離計測機能はありません。入力する距離は自己申告です。タイムの新規入力は60分未満です。

キーワード案：
皇居,ランニング,ランナー,手帳,メモ,タイマー,記録,ジョギング

審査メモ案（実機テスト後に確定）：
本アプリはアカウント登録不要の個人用ランナー手帳です。初期状態にサンプル記録はありません。
1. 最初の「ランナー手帳」でニックネーム、出会った日、特徴、会話を入力し「手帳に保存」。保存後は検索・編集・削除ができます。
2. 「計測する」でタイマーを開始・停止し、「このRUNを保存」。または「25:03.45」などのタイムを手入力して保存。
3. 「記録を比べる」で保存した記録と、同じ距離の前回比を確認。
4. 画面下部「記録をJSONでバックアップ」でOSの共有シートを開きファイルを保存。「バックアップから復元」でJSONを選ぶと記録が置き換わります。
主要機能はオフラインで利用でき、手帳の内容を開発者へ送信する機能はありません。
